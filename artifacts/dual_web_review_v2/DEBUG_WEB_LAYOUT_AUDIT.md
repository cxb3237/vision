# 调试网站布局与状态审计

## 布局

侧栏采用四段网格：固定标题栏、固定关键状态、独立滚动详细区、固定 60 px 操作栏。底栏始终包含“摄像头参数”和“启用/停止位置下发”。参数抽屉仍只覆盖侧栏，不覆盖预览。

浏览器几何测试源码覆盖 1024×600、1280×800、1920×1080，并继续覆盖 800×480、1280×720、720×1280；检查页面整体无滚动、预览与侧栏不相交、底部按钮位于视口内。当前机器没有 Playwright Chromium，几何用例本次标记 skipped，必须在装有浏览器的环境或树莓派平板上执行。

## 信息层级

- 始终显示：毫米位置、识别状态、摄像头、UART、MCU READY、S、F、EN、AGE、`position_tx_hz` 和启停按钮。
- 普通信息：像素 X、置信度、标定、camera/vision FPS、AC、RJ、最近 UART 错误。
- 高级折叠：全部 MCU 字段、NCNN耗时、捕获到结果延迟、丢帧、事件与标定详情。
- 已删除重复的原始 MCU JSON，只保留带中文含义和单位的结构化字段。

## 状态判断

“位置下发运行中”要求 `vision_output_enabled=true`、`serial_online=true`、`mcu_ready=true` 且 `position_tx_hz>0`。其余分支区分未请求、等待UART、等待READY、无有效位置、位置流中断、正在停止、已停止和UART故障。未标定时按钮禁用并显示后端提供的具体错误。
