# Raspberry Pi 5 手工验收

1. 使用有线网络或本地终端执行安装。
2. 确认安装前置阶段热点不会提前激活。
3. 最后激活阶段观察 wlan0 SSH 是否按预期断开。
4. 平板查找 `cxb`，使用 `123@chenzi` 连接。
5. 打开 `http://192.168.50.1/` 和 `http://192.168.50.1:8080/`。
6. 打开网页前停止视觉服务并确认离线提示。
7. 启动视觉服务，确认两站视频流无需刷新自动恢复。
8. 重启 Nginx，确认视频流自动恢复。
9. 重启热点，确认视觉主程序不受影响。
10. 开始录像并持续 10 秒。
11. 停止录像并等待列表自动出现新文件。
12. 核对文件名、分辨率、FPS、codec、大小和完整状态。
13. 浏览器直接播放、拖动进度条、下载视频并检查真实时长。
14. 检查 `systemctl is-enabled cxb-hotspot camera-debug-web nginx vision-touch`。
15. 重启树莓派，完成热点、两个网站、摄像头、录像和主服务的开机验收。
